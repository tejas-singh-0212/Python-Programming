# 🐍 Python Programming Projects

A collection of Python projects built while learning and practicing core programming concepts, ranging from basic scripts to Object-Oriented Programming (OOP) applications.

## Project Overview

This repository contains multiple mini-projects, each focused on applying Python concepts and improving problem-solving skills through practical implementation.

---

## Included Projects

### Sub-Modules

#### Coffee Machine OOP (`coffee_machine_oop/`)
- A command-line simulation of a coffee machine using modular class design for menu handling, resource management, and payment processing.
- Files: `main.py`, `menu.py`, `coffee_maker.py`, `money_machine.py`

#### Quiz Game (`quiz/`)
- An interactive quiz application that manages questions, validates answers, and tracks user progress and score.
- Files: `main.py`, `quiz_brain.py`, `question_model.py`, `data.py`

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/tejas-singh-0212/Python-Programming.git
```

2. Run a project:
```bash
# Single file projects
python <filename>.py

# Sub-module projects
cd <sub-module-folder>
python main.py
```
