# 🐍 Python Programming Projects

A collection of Python projects built while learning and practicing core programming concepts, ranging from basic scripts to Object-Oriented Programming (OOP) applications.

## Project Overview

This repository contains multiple mini-projects, each focused on applying Python concepts and improving problem-solving skills through practical implementation.

---

## Included Projects

### Coffee Machine (OOP)
- A command-line simulation of a coffee machine using modular class design for menu handling, resource management, and payment processing.

### Quiz Game (OOP)
- An interactive quiz application that manages questions, validates answers, and tracks user progress and score.

### Password Generator
- Generates secure random passwords using a combination of letters, numbers, and symbols.

### Caesar Cipher
-   Implements a basic encryption and decryption technique by shifting characters in the alphabet.


---

## Concepts Covered

- Python fundamentals (loops, conditionals, functions)
- Object-Oriented Programming (OOP)
- Modular programming and code organization
- Randomization and basic security concepts
- String manipulation and encryption basics
- User input handling and control flow
- Command-line application development


## How to Run

1. Clone the repository:
```bash
git clone https://github.com/tejas-singh-0212/Python-Programming.git
```
2. Navigate to a project folder:
```
cd Python-Programming/<project-folder>
```
3. Run the project:
```
python main.py
```
