## 🧠 Quiz Game (OOP)

A command-line quiz application built in Python using Object-Oriented Programming.  
The program presents a series of questions, tracks user answers, and calculates the final score.

### Functionality
- Displays questions sequentially
- Accepts user input (True/False or similar)
- Validates answers and updates score
- Shows progress and final result

### Project Structure
- `Question` → Defines the structure of each question
- `QuizBrain` → Controls quiz flow, checks answers, and tracks score
- `data.py` → Stores question data
- `main.py` → Runs the quiz and handles user interaction

### Concepts Applied
- Object-Oriented Programming (OOP)
- Class-based design
- Data separation and modularity
- State management (score & progress tracking)

### How to Run
```bash
python main.py
```
